START

1. Initialize Working Memory with known facts
   Fever, Cough

2. Check all available inference rules.

3. If the conditions of a rule match
   the known facts:

      Apply the rule.
      Generate a new fact.

4. Add the new fact to Working Memory.

5. Check whether the new fact can trigger
   any other rules.

6. If any new rule is satisfied:
      Apply that rule.
      Add the new fact.
      Repeat the process.

7. If no more rules can be applied:
      STOP.

END
