START

1. Create a graph representing the map.
2. Identify all neighbouring regions.
3. Define a set of available colours.

4. Select an uncoloured region.

5. Assign a colour to the selected region.

6. Check its neighbouring regions.

7. IF any neighbour has the same colour:

      Change the colour.

8. ELSE:

      Move to the next uncoloured region.

9. Repeat until all regions are coloured.

10. Display the final map colouring.

STOP
